# quiz-me

One-shot interactive multiple-choice quiz from a Markdown deck, with confidence-before-reveal scoring and a calibration read.

- Requirements: `python3` (no packages). Opens the result in your default browser.
- Install: `cp -r skills/learning/quiz-me ~/.claude/skills/`
- Use: `python3 ~/.claude/skills/learning/quiz-me/scripts/render.py deck.md`
- For spaced repetition with saved progress see the separate `quiz-me-full` skill.
