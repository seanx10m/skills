# decide-ui

Turns a list of items into a single self-contained HTML page for making decisions: swipe left/right triage, or a pairwise tournament bracket.

- Platform: any (opens the page with `open` on macOS, `xdg-open` elsewhere). No dependencies.
- Install: `cp -r skills/agent-ui/decide-ui ~/.claude/skills/`
- Invoke explicitly with `/decide-ui`. Gesture reference code is in `references/`.
