# pave

Active planning alongside a working agent: interrogates in-flight work for problems, grooms what is next, and routes new ideas (issue, parallel worktree, or redirect).

- Requirements: `git`, `gh` (GitHub CLI). Optional: the `browser-preview` and `wt-handoff` skills from this repo.
- Install: `cp -r skills/productivity/pave ~/.claude/skills/`
- Invoke with `/pave`.
